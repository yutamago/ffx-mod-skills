# Agent instructions

This repository holds instructions for AI coding agents that help people make
mods for the Final Fantasy X/X-2 HD Remaster with the Fahrenheit mod
framework.

If you are helping someone make or fix such a mod, read
`skills/fahrenheit-mod/SKILL.md` and the files it links, and follow them.

When editing this repository:

- Keep every fact checkable against the Fahrenheit wiki or source, and link
  the page it comes from. Write in your own words; do not copy Fahrenheit's
  wiki or code.
- Keep `SKILL.md` short; put detail in `references/`.
- Never open issues or pull requests on `fahrenheit-crew` repositories.
